Salon owner

Gérer votre salon sur Skedisy

Positionnement : un système métier pour des rendez-vous préparés, rentables et réservables — pas seulement « un agenda en ligne ». Instagram reste votre vitrine ; Skedisy gère après le clic.

1. Démarrer

  1. Demande d’intégration : /salon/rejoindre ou réclamation de fiche.
  2. Connexion Salon Panel : /salonpanel/
  3. Complétez Profil (adresse, téléphone, Instagram, horaires, photo).
  4. Ajoutez prestations + expertes + planning.

2. Service Engine — prestations, variantes, add-ons

Pour une presta type Knotless, configurez :

  • Base : nom, prix de référence, durée de base
  • Variantes : longueur, finesse, qui apporte les mèches, couleur…
  • Add-ons : curly ends, takedown, lavage… (chacun peut modifier prix + durée)
  • Fiche « avant de réserver » : inclus, prep ✓/✕, photo, note importante

La cliente voit un devis clair ; le calendrier bloque la durée cotée.

3. Fiche publique = mini-site

Photos, avis, prix, Message, Appeler, Instagram. Partagez le lien dans votre bio IG / WhatsApp / Google.

Profil salon → champ Page Instagram + messagerie activée.

4. Politiques (annulation / no-show / retard)

Dans Profil : heures d’annulation gratuite, % annulation tardive, % no-show, tolérance retard (ex. 15 min).

La cliente lit et accepte avant de confirmer — moins de négociation en DM.

Argument marketing prudent : la fonctionnalité est utile ; ne pas affirmer des « no-shows massifs » sans données ops.

5. Messagerie intégrée

Menu Messages du panel : conversations issues de la fiche publique (texte + photos). Répondez ici ; la cliente est notifiée.

6. Marketing automatisé

Menu Marketing :

  • « Mardi, planning à 40 % » → créer une promo ciblée (code salon)
  • « X clientes à échéance cette semaine » → campagne SMS rebooking
  • Brouillons de posts prêts à coller (IG / WhatsApp)
  • Packages multi-visites (ex. pose + entretien) + insight durée prévue vs réelle

Fidélité : réduction sur la même prestation (Profil → programme fidélité).

7. Équipe & planning

Expertes, planning équipe, check-in/out via app Expert. Après un RDV : durée réelle et photo résultat pour apprendre et rebook.

8. Deux propositions de valeur

  1. Garder vos clientes — IG / WhatsApp / Google → lien Skedisy → résa + messages.
  2. En trouver de nouvelles — recherche locale (« Knotless à Paris ») → votre fiche.
