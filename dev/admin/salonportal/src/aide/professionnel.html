Professionnelles / expertes

Travailler avec Skedisy au quotidien

L’app Expert est faite pour votre journée en salon : voir les créneaux, accueillir la cliente, respecter la durée cotée, et clôturer le rendez-vous proprement.

1. App Expert

La gérante crée votre compte à l’inscription du salon. Vous recevez vos identifiants Expert (iPhone / Android).

  • Agenda et réservations du jour
  • Détail cliente + configuration (ex. Knotless moyennes / mi-dos + curly ends)
  • Notes / photos d’inspiration si fournies

Documentation détaillée des écrans : Docs Expert.

2. Déroulé type d’une journée

  1. Ouvrez l’agenda : créneaux déjà bloqués selon la durée devisée (variantes + add-ons).
  2. Check-in à l’arrivée de la cliente.
  3. Respectez la prep indiquée (cheveux propres, mèches salon vs cliente…).
  4. Tolérance retard : définie par le salon (ex. 15 min) — visible sur la fiche publique.

3. Terminer le rendez-vous

Check-out dans l’app. Skedisy peut enregistrer :

  • Durée réelle (prévu vs réalisé) — utile pour ajuster les prochaines cotations
  • Photo du résultat (preuve + historique cliente)
  • Déclenchement éventuel du cycle rebooking (styles protecteurs)

Le salon peut aussi joindre photos / note depuis le panel (Messages / booking).

4. Bonnes pratiques

  • Lisez la config avant de commencer — moins de surprises prix / durée.
  • Si une prep manque, notez-le : le salon pourra ajuster la presta.
  • Gardez le profil à jour (photo, spécialités) pour la fiche salon.
