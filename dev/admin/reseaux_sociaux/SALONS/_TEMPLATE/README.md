# Salon asset pack — template

Duplique ce dossier et renomme-le avec le nom du salon (ex. `Mars-Paris`).

| Dossier | Contenu |
|---------|---------|
| `logo/` | Logo / photo de profil Instagram du salon |
| `exterior/` | Façade, enseigne, rue |
| `interior/` | Espace d’accueil, postes de coiffage |
| `stylist/` | Portraits de l’équipe (avec accord) |
| `service photos/` | Prestations en cours (mains, outils, ambiance) |
| `hairstyle photos/` | Résultats clients (avant/après si possible) |

Lien fiche Skedisy (à noter ici) : `https://skedisy.com/salon/...`
