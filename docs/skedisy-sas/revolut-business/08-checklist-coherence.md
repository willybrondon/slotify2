## Erreurs fréquentes (à éviter)

| Erreur | Conséquence |
|--------|-------------|
| Activité floue (« services divers ») | Demande de précisions / refus |
| Pas de site web | Retard ou refus |
| Siège France ≠ Kbis | Blocage compliance |
| Président = adresse France alors qu'il vit au **Canada** | Incohérence KYC |
| Actionnariat 50/50 au lieu de 70/30 | Blocage UBO |
| Décrire Skedisy comme un salon | Incohérence avec statuts |
| Noms différents (Johnson vs Jonhson) | Rejet KYC |

## Qui fait quoi — récapitulatif

### MPETMI (Président — Canada)

- [ ] Ouvre le compte Revolut Business (app)
- [ ] Passeport + selfie / vidéo KYC
- [ ] Déclare résidence **Canada**
- [ ] Justificatif domicile Canada si demandé

### NDANGUE (France — 70 %)

- [ ] Prépare statuts / Legalstart / Kbis
- [ ] Fournit adresse **siège social** France + justificatif si besoin
- [ ] Fournit infos actionnariat 70 %
- [ ] Vérifie cohérence site + descriptions
- [ ] Peut aider au business plan

### Société SKEDISY SAS

- [ ] Kbis dès disponible
- [ ] skedisy.com en ligne
- [ ] Description activité identique partout

---

## Ordre de passage recommandé

```
1. Finaliser statuts + Legalstart (même adresse, mêmes noms, 70/30)
2. Publier / mettre à jour skedisy.com
3. MPETMI : KYC Revolut (Canada) + infos société
4. Immatriculation → Kbis → upload Revolut sous 48–72 h
5. Business plan PDF si demandé
```

---

## En cas de refus ou demande complémentaire

1. Lire le message Revolut (souvent : document illisible, incohérence adresse, activité unclear).  
2. Corriger **une** source de vérité (Kbis) puis realigner Revolut.  
3. Ne pas resoumettre avec des infos différentes.  
4. Support Revolut Business chat — garder numéro de dossier.
