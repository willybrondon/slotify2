# 3. Documents de la société

Revolut exige des **preuves d'existence légale** de SKEDISY SAS. Les pièces diffèrent selon que la société est **déjà immatriculée** ou **en cours de création**.

---

## Avant immatriculation (votre cas possible)

Si la SAS n'a pas encore de **Kbis** :

| Document | Source | Usage |
|----------|--------|--------|
| **Projet / statuts signés** | Legalstart ou `docs/skedisy-sas/statuts-et-pacte-associes.md` | Preuve du projet |
| **Attestation Legalstart** (si disponible) | Legalstart | Création en cours |
| **Description du projet** | [06-preuve-activite.md](./06-preuve-activite.md) | Activité claire |
| **Capture Legalstart / INPI** | Guichet unique | Dossier déposé |

Revolut peut accepter une ouverture **en attente de Kbis**, puis demander le Kbis sous **X jours** après immatriculation.

---

## Après immatriculation (obligatoire à terme)

| Document | Description | Où l'obtenir |
|----------|-------------|--------------|
| **Extrait Kbis** | < 3 mois | Infogreffe / societe.com / greffe |
| **Statuts à jour** | Version enregistrée au greffe | Legalstart / greffe |
| **SIREN / SIRET** | Identifiants officiels | Kbis |
| **PV de constitution** (si demandé) | Nomination du Président | Dossier de création |

---

## Modèle de liste pour upload Revolut

```
1. Kbis SKEDISY SAS (extrait RCS)
2. Statuts constitutifs SKEDISY SAS
3. [Optionnel] Pacte d'associés (si Revolut demande la structure)
```

---

## Timing recommandé

| Étape | Action |
|-------|--------|
| **J0** | Dépôt création SAS (Legalstart / greffe) |
| **J+3 à J+15** | Réception Kbis → **téléverser immédiatement sur Revolut** |
| **En parallèle** | Président (Canada) termine KYC passeport + selfie |
